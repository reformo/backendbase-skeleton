Backendbase guide diagram runtime

React 18.3.1, React DOM 18.3.1, @xyflow/react 12.10.0.
Build tool: esbuild 0.25.12. Runtime assets require no network requests.
The adjacent lock file pins direct, transitive, and build dependencies.
Guide prose and diagram definitions are maintained independently of this vendor bundle.

Rebuild from the repository root:

guideBuildDirectory=$(mktemp -d)
cp resources/guides/assets/react-flow-runtime.lock.json "$guideBuildDirectory/package-lock.json"
node -e 'const fs = require("node:fs"); const directory = process.argv[1]; const lock = JSON.parse(fs.readFileSync(directory + "/package-lock.json")); fs.writeFileSync(directory + "/package.json", JSON.stringify({private: true, dependencies: lock.packages[""].dependencies}));' "$guideBuildDirectory"
npm ci --prefix "$guideBuildDirectory" --ignore-scripts --no-audit --no-fund
NODE_PATH="$guideBuildDirectory/node_modules" "$guideBuildDirectory/node_modules/.bin/esbuild" resources/guides/assets/react-flow-entry.js --bundle --minify --format=iife --global-name=GuideFlow --target=es2020 --define:process.env.NODE_ENV='"production"' --legal-comments=none --banner:js='/*! Local documentation runtime. Versions, licenses, and rebuild instructions: third-party-notices.txt */' --outfile=resources/guides/assets/react-flow-runtime.js
cp "$guideBuildDirectory/node_modules/@xyflow/react/dist/style.css" resources/guides/assets/react-flow.css

Preserve the package license texts below when distributing the assets.
Regenerate the notice inventory if the lock file or bundled imports change.
