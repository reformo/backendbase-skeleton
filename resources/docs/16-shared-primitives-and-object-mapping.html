01 · Overview

Share stable technical values, not context rules

The shared primitive directory contains small types used across bounded contexts. A primitive should validate its own invariant and provide one stable representation.

Keep business-specific decisions inside their owning bounded context. Do not move a type to Shared only because two classes use it.

03 · Identifiers

EntityId uses UUID version 7

create() and generate() create a UUID version 7 (UUIDv7). fromString() parses persisted or external values and translates invalid input to InvalidResourceId.

Create

Generate a new time-ordered UUIDv7.

Parse

Build the exact subtype from a UUID string.

Serialize

Return the canonical UUID string.

null() creates the all-zero UUID sentinel. Use it only when the surrounding contract defines that value.

04 · Validated strings

Constructors enforce only their current invariant

TypeCurrent behavior
EmailUses PHP email validation. It preserves the original string and does not trim or lowercase it.
NameRequires a byte length of at least two. It preserves whitespace.
Tax identifier typesRepresent private and corporate tax identifiers behind TaxId.
CoordinatesStores longitude and latitude strings without range validation.
Validate the exact contract at the external boundary. Do not assume a primitive normalizes a value unless its source states that behavior.

05 · Password hashes

PasswordHash verifies and replaces Argon2id hashes

verifyHash() compares a sensitive password with the stored hash. changeHashWithNewPassword() returns a cloned value with a new Argon2id hash.

validatePassword() is currently empty. Callers must not treat that method as password-policy enforcement.

06 · Query values

Pagination and filters carry read-model input

Pagination normalizes a non-positive current page to page 1 before total calculation. setTotal() calculates the page count and clamps a page that exceeds it.

Filter stores a query, target fields, and optional criteria. It does not validate SQL field names. A repository must use allowlisted columns and bound parameters.

Pagination rejects non-positive page sizes and offsets greater than PHP_INT_MAX at construction. HTTP collection endpoints reject invalid offsets with status 400 before query dispatch.

07 · Collections and health

Shared transport values have explicit JSON forms

  • JsonSerializableArrayCollection uses a native array and SPL interfaces. It serializes contained values for JSON output without Doctrine.
  • HealthCheckData includes the Git build identifier, numeric status, and status text.
  • Pagination serializes pageSize, page, and total.
  • Notification primitives define provider-independent email, push, and SMS data.

08 · Mapping flow

ObjectMapper turns boundary arrays into typed objects

  1. Payloadcomes from boundary
  2. Sanitizernormalizes values
  3. Callbackcan adjust payload
  4. Field filterkeeps public vars
  5. Valinormaps target type
  6. Resultor validation error

The dependency container uses a filesystem Valinor cache. Development adds a file-watching cache wrapper.

09 · Mapping contract

Only public declared target fields survive filtering

The mapper gets target field names through get_class_vars(). It removes payload keys that do not match a public declared property. Valinor then maps the filtered array with permissive types enabled.

Permissive mapping can convert compatible scalar values. Validate HTTP and command-line input before mapping when silent conversion would change the contract.

10 · Mapping errors

Return structured input errors without Valinor details at the controller

A Valinor MappingError becomes InvalidUserInput. Its context contains the short target class name and an error map indexed by field name.

[
    'target' => 'CreateExampleInput',
    'errors' => ['email' => '...'],
]

11 · Reuse boundaries

Use shared types only for stable cross-context meaning

Good shared candidate

A UUID wrapper, email syntax, date interval constant, or generic pagination value.

Keep in the context

A customer status, order rule, product limit, or role decision owned by one model.

Context code can wrap a shared technical value when it needs additional domain meaning.

12 · Current gaps

Known primitive and mapper limits

  • PasswordHash::validatePassword() has no implementation.
  • Coordinates does not validate numeric format or geographic range.
  • Email and Name do not normalize input.
  • Permissive object mapping can hide scalar-type mistakes.
  • Unknown payload keys are removed instead of reported.
  • HealthCheckData exposes mutable public fields and setters.

14 · Checklist

Add a primitive or mapping target safely

  • The type has stable cross-context meaning.
  • The constructor preserves its invariant.
  • External input is validated before trusted use.
  • Serialization has one documented form.
  • Sensitive values do not appear in logs.
  • Public mapping fields match the input contract.
  • Unknown input-key behavior is intentional.
  • Invalid and boundary tests pass.
