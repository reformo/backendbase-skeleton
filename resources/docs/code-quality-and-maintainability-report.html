06 · Recommendations

Close the control gaps before adding more structure

  1. Introduce typed configuration objects for database, queue, AWS, Redis, and logging settings.
  2. Add explicit diagnostics for queue transport exceptions.
  3. Set a continuous-integration coverage threshold below the current result.
  4. Extend Tolgee tests to API response validation and atomic file replacement.
  5. Create CHANGELOG.md, or remove the requirement from project documentation.
  6. Review whether optional integrations must remain direct runtime dependencies.
Keep changes focused. The architecture does not need a broad rewrite. The highest-value work is typed configuration and explicit queue-failure diagnostics.
